# Start Here - Version 1.4.0

## For Jolinda and Accounting

1. Open the live application: https://redpanda-17.github.io/ranch-expense-tracker/
2. Review the sample PDF and CSV in the `sample` folder.
3. Confirm the fixed mileage rate before employees use mileage reimbursement.
4. Choose a small initial testing group.
5. Ask testers to download a backup regularly.

## For employees

1. Open the website in an approved browser.
2. Complete Settings with your name, department, and report recipient.
3. Add expenses and supporting documents as they occur.
4. Use Current Report to choose a pay period, select expenses, and export PDF or CSV.
5. Keep reports marked Submitted until reimbursement is received.

## For IT

Start with:

- `TECHNICAL_HANDOFF.md`
- `UPGRADE_NOTES.md`
- `QA_RESULTS.md`
- `index.html`, `app.js`, and `app.css`

The current release is a static, local-first application. The long-term company version should use company authentication and centralized storage.
