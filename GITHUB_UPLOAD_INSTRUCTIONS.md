# GitHub Upload Instructions

1. Download a backup from the current live application.
2. Extract the Version 1.4.0 handoff ZIP.
3. Upload the contents of this folder to the repository root.
4. Replace files with matching names.
5. Keep the repository and GitHub Pages URL unchanged.
6. Commit directly to `main` using:

`Release Ranch Expense Tracker v1.4.0`

7. Wait for GitHub Pages to redeploy.
8. Open the live site and confirm Version 1.4.0 appears.
9. Hard refresh and verify existing test data, PDF, CSV, and backup.

The standalone HTML is for review. GitHub Pages should use `index.html`, `app.css`, `app.js`, and the PWA files.
