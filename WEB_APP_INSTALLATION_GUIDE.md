# Ranch Expense Tracker - Web App Installation Guide

Website: https://redpanda-17.github.io/ranch-expense-tracker/

Use the app directly in a browser or install it for quicker access. Use the same browser and browser profile each time because data is stored locally.

## Windows - Microsoft Edge

1. Open the website in Microsoft Edge.
2. Select the three-dot menu.
3. Select Apps or More tools, then Install this site as an app.
4. Select Install.
5. Pin it to Start, the taskbar, or the desktop if offered.

## Windows, Mac, Linux, or Chromebook - Google Chrome

1. Open the website in Chrome.
2. Select the three-dot menu.
3. Select Cast, save, and share, then Install page as app.
4. Some Chrome versions show an Install icon in the address bar instead.
5. Follow the prompts.

## Android - Chrome

1. Open the website in Chrome.
2. Tap the three-dot menu.
3. Tap Install app or Add to Home screen.
4. Follow the prompts.

## iPhone or iPad - Safari

1. Open the website in Safari.
2. Tap Share.
3. Tap Add to Home Screen.
4. Turn on Open as Web App when shown.
5. Tap Add.

## Mac - Safari

On supported macOS versions:

1. Open the website in Safari.
2. Choose File, then Add to Dock.
3. Confirm the app name and select Add.

## After installation

- Open the icon and confirm the footer shows Version 1.4.0.
- Complete Settings before adding expenses.
- Do not use Private or Incognito browsing.
- Download backups regularly.
- If an installed copy shows an older version, close it, reopen it, and refresh the website in the original browser.

## Removing the app

Removing an installed web app may offer an option to delete its browsing data. Do not delete site data unless a current backup has been saved.
