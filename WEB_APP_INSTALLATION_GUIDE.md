# Ranch Expense Tracker - Web App Installation Guide

**Applies to:** Version 1.3.4  
**Last verified:** July 29, 2026

## Read this first

- Install the application from the **hosted HTTPS link provided by Accounting or IT**. The standalone HTML review file is not the installation link.
- Install the app **before entering real expenses** whenever possible.
- Do not use Incognito, InPrivate, or Private Browsing.
- Expense data remains local to the device, browser, and browser profile. Installing the app does not create an account or sync data to another device.
- Download a backup before uninstalling the app, clearing browser data, changing browsers, changing devices, or changing the hosted address.
- After installation, open **Settings > About** and confirm the application shows **Version 1.3.4**.

## Recommended browser by device

| Device | Recommended installation method |
|---|---|
| Windows 10 or 11 | Microsoft Edge |
| Windows, macOS, or Linux | Google Chrome |
| Chromebook | Google Chrome |
| Android phone or tablet | Google Chrome |
| iPhone or iPad | Safari |
| Mac with macOS Sonoma 14 or later | Safari or Chrome |

## Windows 10 or 11 - Microsoft Edge

1. Open Microsoft Edge.
2. Open the Ranch Expense Tracker hosted link.
3. Select **Settings and more (...)** in the upper-right corner.
4. Select **More tools > Apps > Install this site as an app**. Edge may instead show an install prompt in the address bar.
5. Confirm the name **Ranch Expense Tracker**, then select **Install**.
6. When offered, pin it to the taskbar or Start menu.
7. Open the installed app and confirm **Version 1.3.4**.

## Windows, macOS, or Linux - Google Chrome

1. Open Google Chrome.
2. Open the Ranch Expense Tracker hosted link.
3. Select **More (...) > Cast, save, and share > Install page as app**. Chrome may instead show an Install icon in the address bar.
4. Follow the on-screen instructions.
5. Open the installed app and confirm **Version 1.3.4**.

## Chromebook - Google Chrome

1. Open Chrome and go to the hosted link.
2. Select **More (...) > Cast, save, and share > Install page as app** or select the Install icon in the address bar.
3. Confirm the installation.
4. Open Ranch Expense Tracker from the Chromebook Launcher.
5. Confirm **Version 1.3.4**.

## Android phone or tablet - Google Chrome

1. Open Chrome.
2. Open the Ranch Expense Tracker hosted link.
3. Tap **More (...)** to the right of the address bar.
4. Tap **Install and create shortcut > Install**.
5. Follow the on-screen instructions.
6. Open the Ranch Expense Tracker icon from the Home screen or app list.
7. Confirm **Version 1.3.4**.

## iPhone - Safari

1. Open Safari.
2. Open the Ranch Expense Tracker hosted link.
3. Tap the **More** button, then **Share**. Depending on the Safari layout, the Share button may already be visible.
4. Scroll down and tap **Add to Home Screen**.
5. Turn on **Open as Web App**.
6. Tap **Add**.
7. Open Ranch Expense Tracker from the Home Screen and confirm **Version 1.3.4**.

If **Add to Home Screen** is missing, scroll to the bottom of the Share actions, tap **Edit Actions**, and add **Add to Home Screen**.

## iPad - Safari

1. Open Safari.
2. Open the Ranch Expense Tracker hosted link.
3. Tap **Share**, then **More**, then **Add to Home Screen**.
4. Turn on **Open as Web App**.
5. Tap **Add**.
6. Open Ranch Expense Tracker from the Home Screen and confirm **Version 1.3.4**.

## Mac - Safari (macOS Sonoma 14 or later)

1. Open Safari and go to the hosted link.
2. Choose **File > Add to Dock**. You can also select **Share > Add to Dock**.
3. Confirm the app name and select **Add**.
4. Open the app from the Dock, Spotlight, or the Applications folder in your home folder.
5. Confirm **Version 1.3.4**.

**Important for Mac Safari:** Safari web apps keep their website data separate from the normal Safari browser. Install the app before entering real expenses. If expenses already exist in Safari, download a backup first and restore it inside the installed web app.

## iPhone or iPad - Chrome alternative

Safari is the recommended installation path. Chrome also allows a website to be added to the Home Screen:

1. Open Chrome and go to the hosted link.
2. Tap **Share** on the right side of the address bar.
3. Tap **Add to Home Screen**.
4. Confirm the name and tap **Add**.

The resulting behavior can vary depending on the website and iOS/iPadOS version, so use Safari when possible for the controlled trial.

## After installation

1. Open **Settings** and save the employee name, department, and default report recipient.
2. Add one test expense and, when applicable, one test receipt.
3. Close and reopen the installed app to confirm the information remains.
4. Download a backup and confirm the backup reminder clears.
5. Test PDF and CSV downloads or sharing before using the app for a real reporting period.

## Troubleshooting

### The Install option does not appear

- Confirm the app is opened from the hosted **HTTPS** address, not the standalone HTML file.
- Refresh the page and wait a few seconds.
- Confirm the browser is current and not in private-browsing mode.
- On a company-managed device, installation may be blocked by an IT policy. Contact IT rather than changing security settings.

### The installed app shows an old version

- Close the installed app completely.
- Open the hosted link in the same browser and refresh it.
- Reopen the installed app and verify the version.
- If the old version remains, make a backup before clearing any site data or reinstalling.

### Expenses are missing after installation

The app may have been opened in a different browser, browser profile, device, or Safari web-app data container. Return to the original location, download a backup, then restore that backup in the installed app.

### Before uninstalling

Download a backup first. During uninstall, do not select an option such as **also delete data** unless the employee has a confirmed backup and intends to remove all local records.
