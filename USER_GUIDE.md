# Employee User Guide - Version 2.1.2

## 1. Sign in
Ranch Expense Tracker requires an account. Sign in with your approved Pizza Ranch email and password. Your synchronized expense and report information will load automatically.

## 2. Existing Version 1.x data
If a device still contains older Ranch Expense Tracker data, Version 2 may offer a one-time import after sign-in. Only import from the device that contains the authoritative legacy history. The original Version 1.x data remains on that device as a safety copy.

## 3. Add an expense
Attach a receipt when available, then enter the amount, merchant, category, date, and any useful category details.

Descriptions are required for selected broad categories such as Education, Other, and broad subcategories beginning with Other. Project/trip tags remain optional.

After the expense saves and syncs successfully, the receipt is stored in the cloud. The app does not intentionally keep a permanent local receipt copy after the cloud upload is confirmed.

## 4. Mileage
Enter the starting location, destination, and total miles traveled. Upload route documentation when useful. Enter the actual total miles being reimbursed.

## 5. Saved defaults
Saved people, organizations/merchants, locations, vehicles, tags, and mileage routes synchronize with your account and can be managed under **Settings > Saved Defaults**.

## 6. Build the current report
Use the pay-period helper when appropriate and select the expenses to include in the current report.

The Dashboard separates:
- **Unreported Expenses** — expenses not currently selected for the report
- **Current Report Total** — expenses currently selected for the report

## 7. Download the report
- **Download PDF** creates the reimbursement report with the supporting documents needed for Accounting review.
- **Download CSV** creates a spreadsheet-friendly export.

The employee app does not run receipt OCR during PDF generation. Accounting reviews the attached receipt/supporting document as part of the normal reimbursement process.

## 8. Submitted reports
Submitted reports and their attached expenses are locked from normal employee editing or deletion. Supporting files for submitted expenses also cannot be replaced or removed by the employee.

Submitted reports remain available under **Past Reports** for PDF/CSV download.

## 9. Viewing receipts
Cloud-backed receipts are downloaded only when needed for viewing or report generation. A receipt opened in the app is treated as a temporary viewing file and is released when the viewer closes.

If the employee explicitly downloads a receipt to their device, that downloaded file is outside the app's temporary-viewing cleanup.

## 10. Cloud sync and offline use
Expenses, reports, receipt metadata, current report state, and saved defaults synchronize automatically while signed in.

The app can maintain temporary/offline working data on the device so an interrupted connection does not automatically mean the cloud record is lost. Changes made offline retry after connectivity returns.

## 11. Sign out
Use **Settings > Account > Sign Out**. Signing out clears the signed-in user's Version 2 working cache from that device while leaving cloud records intact.

## 12. Data exports and support
Use **Settings > Data & Support** for available exports and support information.
