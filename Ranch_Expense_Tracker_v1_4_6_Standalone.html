What is included in Version 1.4.6
  • Fixed iPhone/iPad PDF downloads so Download PDF targets a single .pdf file rather than opening a PDF/share flow that can include both a webpage link and the document.
  • Apple mobile devices now receive generated PDFs through a generic binary-download MIME type while preserving the normal .pdf filename.
  • PDF downloads use same-window download handling instead of creating a second link/tab fallback.
  • Fixed stale-version behavior caused by the offline service worker continuing to serve an older cached app after GitHub Pages was updated.
  • The hosted app now explicitly checks for a newer service worker and bypasses HTTP caching for service-worker update checks.
  • New service-worker versions activate immediately and take control without requiring employees to clear site data.
  • When online, navigation uses the newest network copy of Ranch Expense Tracker; the cached copy is now an offline fallback instead of the first choice.
  • Future app updates can automatically reload once when a newly activated service worker takes control.
  • Receipt previews can now be tapped/clicked to open a larger viewer before the expense is saved.
  • Image receipts support 75%–400% zoom, plus tap/click toggling between fit and 200%.
  • PDF receipt previews open in the larger viewer and can use the browser/PDF viewer's own zoom controls.
  • PDF export now uses adaptive receipt-image compression targeting roughly 120 KB per image when practical, while keeping a minimum quality/resolution floor for legibility.
  • Add Expense now shows the selected receipt or route document at the top of the form before the expense is saved.
  • Image receipts display an inline image preview; PDF receipts display an embedded preview when supported by the browser.
  • Editing an existing expense also shows its currently stored receipt so the user can verify it before replacing it.
  • Report and backup actions now use a simpler download-first workflow for broader device/browser compatibility.
  • Email and Share buttons were removed from report exports; download the PDF/CSV and attach or share it using the device itself.
  • Backup actions were simplified to Download Backup and Import Backup.
  • New backups use a .ranchbackup file extension for more predictable mobile downloading; older .json backups can still be imported.
  • The download helper now keeps generated file URLs alive longer on mobile devices and falls back to opening the file when direct download is unsupported.
  • Receipt photos are automatically resized and JPEG-optimized when attached, reducing local storage, backups, and report size.
  • PDF export also optimizes older image receipts and avoids duplicating the same photo as both a rendered receipt page and an embedded attachment.
  • PDF and other non-image supporting documents are preserved as attachments without image conversion.
  • A faster receipt-first Add Expense layout with the original broad categories.
  • Subcategory-specific fields appear only when they apply.
  • Description is required for Education, Supplies, Other, and any broad Other subcategory.
  • Mileage uses route documentation instead of a purchase receipt.
  • Optional project or trip tags support searching, filtering, and report selection.
  • Saved people, organizations, locations, vehicles, and tags use searchable dropdowns with an Add New option.
  • Choose Pay Period fills the 1st-15th or 16th-end-of-month dates and suggests a report name that can be overridden.
  • Current Report uses an optional Report Note instead of a required overall business purpose.
  • Past Reports use Submitted and Reimbursed statuses and can be reopened for corrections.
  • PDF download, CSV download, backup/restore, and local receipt storage remain available.
